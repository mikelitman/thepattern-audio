# The Pattern: podcast audio

This repository hosts the audio files for **[The Pattern](https://thepattern.media)**, a daily culture-intelligence brief on the signals shaping brands and culture.

Each edition is published as a dated MP3 (`YYYY-MM-DD.mp3`), with an optional chapters file (`YYYY-MM-DD-chapters.json`) alongside it. These files are the enclosures referenced by the podcast feed, so the audio is served from a stable, versioned home.

- **Read and subscribe:** [thepattern.media](https://thepattern.media)
- **Format:** one MP3 per edition, named by publication date
- **Chapters:** where present, `*-chapters.json` carries chapter markers for that edition
